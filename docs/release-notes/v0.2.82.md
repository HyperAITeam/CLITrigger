# v0.2.82 — Analytics fixes, Loops back in Auto Tasks, and a tidier UI

Release date: 2026-11-25
Previous version: v0.2.81

## Summary

The Analytics tab now reports numbers you can trust. Tasks are credited to the right CLI instead of "Unknown", token totals include cache tokens, and **Clear** actually resets the stats. The Automation hub loses its separate Loops tab: loop rules are an option on any auto task again. A few confusing indicators are gone, and the bottom chip bar only shows running sessions. On mobile you can now scroll back through terminal output with your finger. You can also unlink a doc folder straight from the Documents tab.

## Highlights

### Analytics you can trust

- **No more "Unknown" CLI.** Tasks that don't pick a CLI run on the project default, and they are now counted under that CLI. Before, they were all grouped as "Unknown".
- **Token totals include cache reads and writes.** These make up most of a Claude run, and the cost is billed on them too, so tokens and cost now describe the same work. Expect much larger token numbers: existing tasks are recounted automatically the first time the app starts.
- **Clear works.** Tasks created earlier on the same day as a reset were still counted after **Clear**. The 7d / 30d / 90d filters were off by up to a day for the same reason.
- **Daily charts use your local date.** Before, they used UTC, so in time zones ahead of UTC a task created early in the morning landed on the previous day.
- **Multi-round tasks add up.** A task continued with **Continue** used to keep only the latest round's cost. Every round is now included.
- The cost/tokens toggle on the daily chart showed raw translation keys. It now shows proper labels.
- Where the cost comes from: it is Claude Code's own estimate at API list prices, not your subscription bill. Codex, Antigravity, and interactive runs don't report usage, so they count as $0.

### Loops are an option on Auto Tasks again

- The Automation hub tabs are now **Auto Tasks · Discussions · Routines · Analytics**. The separate **Loops** tab is gone.
- Every task, with or without loop rules, appears in **Auto Tasks**. Loop tasks still show their round badge.
- To make a task loop, check **Repeat until a done rule is satisfied (loop)** in the task form. Your project's default loop rules are prefilled.
- Old `?tab=loops` links open **Auto Tasks**. Nothing changes for MCP: `create_todo` still accepts `loop`.

### Fewer confusing indicators

- **Review Queue**: the red / yellow / green dot on each card is gone. It was graded only on how many lines changed, not on actual risk.
- **Bottom chip bar**: minimized windows whose sessions are not running (pending, done, failed, or stopped) no longer get a chip. The window layout is kept, so the chip comes back when the session starts again. Chips for windows popped out into their own OS window always stay.

### Scroll terminal history on mobile

- Drag up and down on a terminal to scroll through its history. Before, the invisible input layer used for Korean typing swallowed every touch.
- Tapping still brings up the keyboard. There is no momentum scrolling, and full-screen TUIs that keep no scrollback can't be scrolled this way.

### Unlink doc folders from the Documents tab

- Right-click a linked folder (`@alias`) and choose **Unlink folder**. Only the link is removed; the files are left alone.
- If a linked folder can't be found (deleted, or on a drive that isn't plugged in), it shows struck through with a warning icon and a "Folder not found" tooltip. It is never removed automatically, because a missing drive looks the same as a deleted folder.

## Install / Update

```bash
npm i -g clitrigger@0.2.82
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.82.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.82.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
