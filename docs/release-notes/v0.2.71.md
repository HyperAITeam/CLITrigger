# v0.2.71 — plugin management in the Harness panel, hooks & skills for Codex and Antigravity

Release date: 2026-11-05
Previous version: v0.2.70

## Summary

The Harness panel can now list installed plugins and turn them on or off — per project for Claude, globally for Codex and Antigravity. The Codex and Antigravity tabs also gain the same hook and skill management the Claude tab already had. In the Vault file explorer, "Send to terminal" in the right-click menu now opens as a submenu.

## Highlights

### Plugin list with on/off toggles (Claude tab)

- Shows the plugins that apply to the current project: user-scope plugins plus project/local-scope plugins installed for this path.
- A checkbox writes a per-project `enabledPlugins` override. If `.claude/settings.local.json` already has a value for that plugin it is updated there; otherwise `.claude/settings.json` is used.

### Hooks, skills, and plugins for Codex and Antigravity

- **Skills**: both CLIs read `.agents/skills/`, which can now be viewed, edited, and toggled — same `SKILL.md` ↔ `SKILL.md.disabled` rename as the Claude tab.
- **Hooks**: Codex uses `.codex/hooks.json` (same structure as Claude; disabled entries are kept in `hooks.disabled.json`). Antigravity toggles the per-name `enabled` flag in `.agents/hooks.json`.
- **Plugins**: Codex edits only the `enabled` line of `[plugins."id"]` in `~/.codex/config.toml`; Antigravity edits `~/.gemini/config/config.json` (the same file `agy plugin enable/disable` uses). Neither CLI supports project-level plugin settings, so these toggles apply globally.
- Only installed plugin IDs can be toggled.

### Vault: "Send to terminal" submenu

- Click or hover for 300 ms to open a submenu to the right with the terminal list, "New terminal", and the include-link toggle. It flips to the left when there isn't enough room on the right.
- Scrolling the list inside the menu no longer closes it.

## Install / Update

```bash
npm i -g clitrigger@0.2.71
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.71.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.71.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
