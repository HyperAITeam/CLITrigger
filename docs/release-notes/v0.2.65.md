# v0.2.65 — Per-skill and per-hook toggles, notifications jump to the session, lazy web panel tabs

Release date: 2026-10-07
Previous version: v0.2.64

## Summary

The Harness tab can now switch individual skills and hooks off and back on without deleting them. Clicking a desktop notification now takes you straight to the terminal session that raised it, including when that session is minimized in the dock or running in the desktop app. The embedded web panel no longer loads every restored tab at startup: a tab's page is created only once you actually look at it, which cuts memory noticeably when several heavy sites are kept open. Two SVN panel annoyances are fixed: the draft commit message no longer disappears when you switch tabs, and the change list refreshes after closing the properties dialog.

## Highlights

### Harness: toggle skills and hooks individually

- **Skills.** Each skill in the Skills panel has a checkbox. Unchecking it hides the skill from Claude while keeping the file and its contents; disabled skills are shown dimmed and can still be opened and edited. Editing a disabled skill does not re-enable it.
- **Hooks.** Each hook entry in the Hooks panel has the same toggle. Disabled hooks are parked outside `settings.json` so Claude never sees them, and re-enabling puts them back exactly where they were. Parked hooks stay visible in the panel under their event.
- Claude CLI only. Codex and Antigravity do not expose skills or hooks through the Harness tab.

### Notifications: click to jump to the session

- Clicking a notification about a terminal session (agent finished, waiting for input, and so on) now opens or focuses that session. If its window is minimized in the dock it is restored, and the right tab is activated inside the group.
- In the desktop app the OS window is raised as well, so the click works even when CLITrigger is behind other windows.

### Web panel: tabs load lazily

- Restored web panel tabs are no longer all loaded when the project opens. A tab's page is created the first time it is the active tab while the panel is visible, and stays loaded after that, so switching back never reloads it.
- Each web panel tab is a separate renderer process, and sites like Notion or Atlassian can take several hundred megabytes each. Idle tabs now cost nothing until you click them.

### SVN panel fixes

- The commit message draft survives switching to another tab and back.
- The change list refreshes whenever the properties dialog closes, not only after a save.

## Migration

- No action required. Disabled skills are stored as `SKILL.md.disabled` next to the original, and disabled hooks in `.claude/hooks.disabled.json`; both are plain files you can inspect or remove by hand.

## Install / Update

```bash
npm i -g clitrigger@0.2.65
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.65.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.65.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
