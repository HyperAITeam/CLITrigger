# v0.2.83 — Multi-select in Documents and Git, clearer session chips, new README demo

Release date: 2026-11-27
Previous version: v0.2.82

## Summary

You can now select many files at once in two places. In the Documents file explorer, Shift/Ctrl-click a range and right-click to act on all of them. In the Git tab, a select-all checkbox and Shift-click range selection work in both the staged and unstaged lists. The session chips at the bottom of the screen now use icons and plain-language tooltips instead of colored dots. The README has a new demo GIF and terminal screenshot.

## Highlights

### Multi-select in the Documents file explorer

- **Shift+click** selects every visible row between the last clicked file (or the open file) and the one you click.
- **Ctrl/Cmd+click** adds or removes single files.
- **Right-click on a selection** applies the menu to all selected files, with an "N selected" header: open, reveal in explorer, pin/unpin, copy paths (one per line), hide/unhide/unlink, send to terminal, and send to a task (one task referencing all of them).
- Right-clicking a row outside the selection clears it and acts on that row only, as before.

### Faster staging in the Git tab

- Each changed-files list (staged and unstaged) has a **select-all checkbox**. It shows a partial state when only some files are checked.
- **Shift+click** a checkbox to check or uncheck the whole range from the last row you clicked in that list.

### Session chips you can read at a glance

- In the chip bar at the bottom, a session waiting for input shows a question-bubble icon and a finished session shows a check icon. Before, both were a colored dot.
- Before, blue meant "working" on the window tab but "done" on the chip. That mismatch is gone.
- Tooltips show the notification text in your language instead of raw English status names.

### New README demo

- The demo GIF now walks through one real session: the wiki shown as a knowledge graph, four terminals docked into a 2×2 grid, three Claude agents working in parallel, leftover work handed to auto tasks over MCP, and a Git commit.
- The terminal screenshot now shows real docked sessions, and the README intro describes this workflow.


- **Windows (portable)**: `CLITrigger-0.2.83.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
