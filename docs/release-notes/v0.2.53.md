# v0.2.53 — Web panel in the planner, svn:externals table editor, Git ignore from the file list

Release date: 2026-09-03
Previous version: v0.2.52

## TL;DR

The planner gains a **Web panel** that embeds any website (Notion by default) inside the desktop app, so you can keep your notes next to your tasks without leaving CLITrigger. SVN users get a TortoiseSVN-style **svn:externals table editor** with revision log lookup and HEAD-revision discovery. In the Git file status view you can now right-click a changed file and **add it to .gitignore**. Also fixed: the review queue's detail log viewer now fills the whole panel, and orchestrator-copied task images are no longer picked up by Git.

## Highlights

### Planner: Web panel (desktop app)

- A new **Web panel** entry in the planner sidebar shows a URL you enter (defaults to `notion.so`) inside the desktop window. Logins persist across restarts.
- The embedded page runs isolated from the app: no scripts are injected, only `http(s)` URLs load, and popups or external links open in your OS browser.
- In the browser build, sites such as Notion refuse to be embedded, so the panel offers an **Open in browser** button instead.

### SVN: svn:externals table editor

- Edit externals as a **Path / URL / Peg / Operative / HEAD** table instead of raw property text.
- **Show log** loads the external URL's revision history; click a revision to use it as the peg revision.
- **Find HEAD-Revision** looks up the current HEAD of every external URL in one pass.
- Relative URL forms (`^/`, `//`, `/`, `../`) are resolved to absolute URLs on the server. Lines that cannot be parsed (comments, unusual syntax) are kept verbatim, and you can switch to **Edit as text** at any time.

### Git: add a file to .gitignore from the file status list

- Right-click any staged or unstaged file and choose **Add to .gitignore**. The path is appended to the checkout's root `.gitignore` as an anchored `/path` entry, skipping duplicates.
- Works on the selected session worktree as well as the main checkout. Untracked files disappear from the list immediately.
- Already-tracked files still need `git rm --cached` to leave the index; this action only writes the ignore rule.

### Fixes

- **Review queue**: the detail panel's log viewer was capped at 256 px and left most of the panel empty. It now fills the full panel height. Inline log viewers elsewhere keep their previous compact size.
- **Task images**: attached images the orchestrator copies into the working directory (`.task-images/`) are now git-ignored, so they no longer show up as untracked changes or slip into commits.

## Install / Update

```bash
npm i -g clitrigger@0.2.53
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.53.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.53.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
