# v0.2.51 — SVN revision diffs & UI consistency overhaul

Release date: 2026-09-03
Previous version: v0.2.50

## TL;DR

Right-click a commit in the SVN log to see its full diff, or compare it against your current working copy. The UI got a large consistency pass: a new self-hosted Pretendard Variable font, lucide icons everywhere, a shared Button component, and every native browser `confirm`/`prompt`/`alert` replaced with in-app dialogs and toasts. The memory editor gained Ctrl+F search, and Claude settings can now be ported to Antigravity/Codex with one click.

## Highlights

### SVN: revision diffs from the log

- Right-click a commit in the SVN log view for two new actions: **Show changes** (the full diff of that revision) and **Compare with working copy** (that revision vs. your current local state, including uncommitted edits).
- Multi-file diffs now render with per-file section headers, so file boundaries stay visible.
- Changelist quality of life: click an empty area of the file list to create a new changelist, and rename one from its right-click menu.

### UI consistency overhaul

- New typography: self-hosted **Pretendard Variable** (OFL-licensed) plus a system mono stack.
- Emoji and symbol characters replaced with **lucide icons**, with unified icon sizing and stroke weight.
- Inline action buttons migrated to a shared **Button** component; modal shells and rounding tiers unified.
- Visual noise removed: particle background, background gradients, entry animations, and global `transition: all` are gone — only hover/press states remain.
- Raw palette colors normalized to status/accent design tokens; dark-mode background bugs fixed across the board.

### No more native browser dialogs

- All native `confirm`/`prompt` call sites (30+) now use the in-app **useDialog** system, and native `alert`s were replaced with toasts — zero browser-native popups remain, so nothing blocks the Electron/web UI thread.

### Harness tools

- Memory file editor: **Ctrl+F** text search and a full-width drag handle for resizing.
- One-click button to port your Claude setup (CLAUDE.md + skills) to **Antigravity/Codex AGENTS.md**.

### Copy & i18n

- A copy-editing pass over UI text: consistent tone, trimmed verbose help text.

## Install / Update

```bash
npm i -g clitrigger@0.2.51
```

- **Windows (portable)**: `CLITrigger-0.2.51.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
