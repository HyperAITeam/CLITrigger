# v0.2.72 — one-click MCP setup, new MCP prompts, and a tools & prompts browser

Release date: 2026-11-16
Previous version: v0.2.71

## Summary

Connecting an AI CLI to CLITrigger over MCP is now a button click: Settings → MCP shows each installed CLI (Claude Code, Antigravity, Codex) with its registration status and a Register / Unregister button. Four MCP prompts arrive — hand the conversation off to a new session, split remaining work into parallel auto tasks, save lessons to the project wiki, and get a project status briefing. The MCP panel also gains Tools and Prompts tabs that list everything a connected CLI can use.

## Highlights

### One-click MCP registration

- Settings → MCP → **Connect** lists Claude Code, Antigravity, and Codex with a status dot: registered, registered with a different address or token (for example after the port changed), not registered, or not installed.
- **Register all detected CLIs** registers every installed CLI that isn't set up yet; each row also has its own Register / Re-register / Unregister button.
- Registration always targets this machine's loopback address on the port the server is actually using, so it works the same even when you open the settings remotely through a tunnel.
- Claude Code is registered at **user scope**, so CLITrigger's tools are available in every folder, not only the one the command ran in.
- If you registered Claude Code earlier with the old copy-paste command, that entry was folder-local; the panel shows Claude as not registered until you click Register.
- The copy-paste setup moved under **Manual setup**. The Antigravity command and the Codex snippet were corrected — the previous ones did not match those CLIs' actual syntax. Codex is given as a `config.toml` snippet, since `codex mcp add` cannot set an auth header.
- When the desktop app has to start on a different port because the usual one is taken, the MCP panel warns that registered clients can't reach it.
- The Settings dialog now scrolls when its content is taller than the window.

### New MCP prompts

Run them as slash commands in your CLI (Claude Code syntax shown; arguments in brackets are optional):

- `/mcp__clitrigger__handoff [instruction]` — summarizes the conversation and creates a new CLITrigger session with that summary held as its first prompt. You preview it and send it when you start the session.
- `/mcp__clitrigger__delegate [scope]` — splits the remaining work into independent auto tasks. Work that touches the same files stays in one task, tasks get a verification loop when the project has a test/typecheck/build command, and relevant wiki notes are injected automatically. Tasks are created but not started.
- `/mcp__clitrigger__remember [topic]` — saves decisions, pitfalls, and conventions from the conversation to the project wiki, merging into an existing note on the same topic and following the wiki's schema note.
- `/mcp__clitrigger__status` — read-only briefing: task counts, what's running, failed tasks with the cause pulled from their logs, and finished tasks not yet merged.

### New MCP tools

- `list_todos` — a project's tasks with their status.
- `list_wiki_nodes` / `update_wiki_node` — read the wiki and update existing notes.
- `create_todo` accepts `memory_inject_mode` (`none` / `all` / `auto`), so tasks created over MCP can receive wiki context.

### Tools and Prompts tabs

- Settings → MCP → **Tools** lists all 24 tools grouped by area (projects, auto tasks, planner, routines, terminals, wiki) with their descriptions.
- **Prompts** shows each prompt's title, description, slash command, and arguments, with a copy button.
- The lists come straight from the running MCP server, so they always match what your CLI sees. New tools appear in a CLI after you open a new session or reconnect (`/mcp` in Claude Code).

### Sessions created outside the UI appear immediately

- Sessions created over MCP (for example by `handoff`) now show up in the project's session list without a page refresh.

## Install / Update

```bash
npm i -g clitrigger@0.2.72
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.72.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.72.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
