# v0.2.70 — new-tab shell picker, tab reordering, local paths in the web panel

Release date: 2026-11-02
Previous version: v0.2.69

## Summary

The new-tab button now has a ▾ menu for picking which shell or AI CLI to open, and tabs can be dragged to reorder them within the tab bar. The web panel's address bar opens local file paths and scheme-less localhost addresses. Zooming the Vault document preview no longer makes tables, code blocks, and headings overlap.

## Highlights

### Pick a shell or AI CLI from the new-tab menu

- Click the ▾ next to + (like Windows Terminal) to choose from detected shells — cmd, PowerShell, pwsh, Git Bash, WSL on Windows; entries from `/etc/shells` on macOS/Linux — or Claude, Antigravity, and Codex.
- The chosen shell is remembered per session. Plain + and Ctrl+T still open the default shell.

### Drag tabs to reorder

- In a stack with two or more tabs, dragging a tab inside the tab bar reorders it. Dragging outside the tab bar keeps the existing behavior (move the window, or detach/dock the tab).
- Works in both the main window and pop-out windows.

### Fix: local paths in the web panel address bar

- Drive paths (`C:\...`), UNC paths, and POSIX absolute paths are converted to `file://` URLs instead of being mangled with `https://`.
- Scheme-less local server addresses like `localhost:5173` or `127.0.0.1:3000` open over `http://`.
- `file://` tabs are labeled with the file name.

### Fix: overlapping lines when zooming the Vault document preview

- Line height now scales with the zoomed font size, so tables, code blocks, and headings no longer overlap.
