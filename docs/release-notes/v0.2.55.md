# v0.2.55 — Web panel fullscreen actually goes fullscreen, collapsible planner sidebar

Release date: 2026-09-03
Previous version: v0.2.54

## TL;DR

Two planner fixes on top of v0.2.54. The **fullscreen** button on the Web panel was stuck at the size of its card instead of covering the app window; it now expands to the full window as intended. The planner **sidebar** (pages, calendar, list, web panel) can now be collapsed to a thin strip on the left to give the content pane the whole width.

## Highlights

### Planner: Web panel fullscreen fix

- **Fullscreen now covers the window**: in v0.2.54 the toggle only grew the panel to the edges of its own card. The card style applies a hover lift (a CSS transform), and a transformed ancestor becomes the positioning root for a fixed-position child, so the "fullscreen" panel was pinned inside the card and clipped by it. The Web panel wrapper now uses the static card surface without the hover lift, and the panel expands over the whole app window without reloading the embedded page.

### Planner: collapsible sidebar

- **Collapse to the left**: a new collapse button sits next to **+** in the sidebar header. Collapsing hides the page list and view switcher and leaves a narrow strip with an expand button, so the page, list, calendar, or web panel gets the full width.
- **Remembered**: the collapsed state is saved per browser and restored on reload.
