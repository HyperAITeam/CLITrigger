# v0.2.78 — Mark review queue items as reviewed, red sidebar badges

Release date: 2026-11-23
Previous version: v0.2.77

## Summary

You can now clear items from the review queue after checking them, without merging or deleting anything. The todo and its branch stay in the project; the item just leaves the queue and the sidebar badge. If you run the todo again and it produces a new result, it comes back to the queue. The review queue badge in the sidebar now uses the same red number badge as workspace alerts.

## Highlights

### Mark reviewed in the review queue

- Each card has a **Mark reviewed** button next to **Discard**. Unlike Discard, it keeps the todo, its worktree, and its branch in the project.
- **Mark all reviewed** in the header hides every item currently shown, after a confirmation. It follows the active filter and time window: with **Risky** selected, only risky items are hidden; with **24h** selected, older items are untouched.
- A hidden item comes back when the todo changes status again (for example, you re-run it or request changes). Other edits, such as cleaning up its worktree, keep it hidden.
- The token and todo totals at the top of the queue count only items still in the queue.

### Sidebar badges

- The review queue count is now a red number badge, matching workspace alerts.
- In the collapsed sidebar, the review queue shows the same red count instead of a plain dot.

## Migration

- None needed. The database column for reviewed items is added automatically on first start.
