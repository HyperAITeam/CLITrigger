# v0.2.57 — Web tab moves to the front of the project tab bar

Release date: 2026-09-07
Previous version: v0.2.56

## TL;DR

A small follow-up to the Web panel promotion in v0.2.56. The **Web** tab now sits **first** in the project header tab bar, ahead of Files, so the embedded browser is one click away when you open a project. Nothing else changes.

## Highlights

### Web tab is now the first project tab

- **New order**: Web → Files → Planner → Sessions → Automation → Git → SVN (Git and SVN still appear only when the project uses them).
- Previously the Web tab was placed between Automation and Git, which made the most frequently used panel the hardest to reach.
- Tab behavior is unchanged: the `?tab=web` deep link, multi-tab browsing, and persisted tab state all work as before.
