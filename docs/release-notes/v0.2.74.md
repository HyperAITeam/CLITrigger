# v0.2.74 — folder and tag grouping in the doc graph, PDF preview fix

Release date: 2026-11-18
Previous version: v0.2.73

## Summary

The doc graph now groups docs by folder by default: each folder is one node, and clicking it opens just that folder. You can also tag docs right in the graph, color nodes by tag, and group by tag instead. Terminal sessions can be reordered by dragging, and a running Claude session can hand its remaining work off to automated tasks with one button. PDF previews, which had been showing a blank white pane, render again.

## Highlights

### Doc graph: group by folder (new default)

- Each folder appears as a single node showing its doc count. Click it to see only what's inside.
- A breadcrumb at the top shows where you are and takes you back up. Docs outside the folder that link into it appear as faded nodes, and the folder holding the open doc is outlined.
- Links between folders are merged into one edge whose thickness reflects how many links it carries.
- Three toolbar buttons switch between **By folder**, **By tag**, and **No grouping**. The choice is remembered per project.
- Large vaults lay out faster because there are fewer nodes to place.

### Doc graph: tags

- Right-click a doc → **Edit tags** to add or remove tags. They are stored in the app, so your markdown files are not changed. Tags already in a file's frontmatter or written inline as `#tag` still show up, but can't be removed from the graph.
- Right-click a folder → tag every doc inside it at once.
- Nodes are colored by their first tag. Click a tag in the editor to make it the first one.
- In **By tag** mode, each doc is grouped under its first tag.
- The legend lists every tag. Click a tag name to highlight its docs, or click its color dot to pick a custom color.
- Tags follow docs when they are renamed or moved, including drag-moves in the file explorer.
- Fixed: with an empty search, every doc node was drawn green, so tag colors never showed.

### Terminal sessions

- **Drag to reorder** the session list. Sessions grouped into one window move together. Press Esc to cancel a drag.
- **Hand off to automated tasks** — running Claude sessions have a new button next to Diff. It runs `/mcp__clitrigger__delegate` in that session, which splits the remaining work into automated tasks.
- When delegated work depends on changes that aren't committed yet, it no longer stops. If the session is in the project's main checkout, the work becomes a task that runs there without a worktree.

### Fixes

- **PDF preview** — PDFs in the doc preview showed only a white pane since the security hardening in v0.2.25. They render again.
- **MCP changes show up right away** — todos, sessions, planner items, routines, and projects created or deleted through MCP now appear in the UI without a refresh. This includes after switching projects.
- **Duplicate project entries** — adding a project could briefly list it twice.

## Install / Update

```bash
npm i -g clitrigger@0.2.74
```

- **Windows (recommended)**: `CLITrigger-Setup-0.2.74.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.74.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
