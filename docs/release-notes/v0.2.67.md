# v0.2.67 — Worktree auto-commit, SVN commit templates and changelist ordering

Release date: 2026-10-14
Previous version: v0.2.66

## Summary

This patch release makes git worktrees safer to merge and adds several quality-of-life features to the SVN panel. Uncommitted changes left in a task worktree are now committed automatically when the task finishes and before any merge, so work is no longer silently left behind. The SVN status panel gains reusable commit message templates, a "Changes" entry in the move-to-changelist menu, right-click changelist creation, and drag-to-reorder section headers. The web panel can open the current page in your system browser, and vault previews now resolve root-absolute image and link paths correctly.

## Highlights

### Git worktrees: auto-commit before merge

- **Leftover changes are committed automatically.** When a TODO or session process exits, any uncommitted changes in its worktree are committed. The same happens right before a merge from a TODO, chain, discussion, or the Git panel.
- **Per-project toggle.** A new "auto-commit" switch in the project settings worktree section controls this. It is on by default. When turned off, a merge is refused if the worktree still has uncommitted changes, so nothing is merged half-done.

### SVN panel: commit message templates

- A new "Templates ▾" menu next to the Commit button lets you save the current message as a named template and reuse it later. Templates are stored globally in the browser.
- Clicking a template appends it after the existing message. Shift+click replaces the message instead.
- Templates can be deleted from the same menu.

### SVN panel: changelist management

- The "Move to changelist" submenu now lists the default "Changes" bucket as a regular entry, replacing the separate "Remove from changelist" item. The file's current changelist is hidden from the list.
- Right-click an empty area of the file list to create a new changelist.
- Drag a changelist section header onto another to reorder them. The order is remembered per project.

### Web panel

- The address bar has a new button that opens the current URL in your default system browser.

### Vault preview fix

- Markdown images and links that use root-absolute paths such as `/assets/images/a.svg` (common in Jekyll and other static-site posts) are now resolved against the project root instead of the document's directory. Previews that used to show broken images now render.

- **macOS**: `.dmg` / **Linux**: `.AppImage`
