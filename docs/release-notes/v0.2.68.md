# v0.2.68 — cmd as default Windows shell, grouped session list, reliable session start

Release date: 2026-10-27
Previous version: v0.2.67

## Summary

New shell tabs on Windows now open Command Prompt instead of PowerShell. The session list visually joins sessions that live in the same window as tabs, so you can tell at a glance which terminals are docked together. A Windows pre-flight bug that intermittently failed session starts with "claude · failed" is also fixed.

## Highlights

### Command Prompt is the default shell tab on Windows

- "New shell tab" (and Ctrl+T) now spawns `cmd.exe` instead of `powershell.exe`. The session list labels it "Raw Shell (Command Prompt)".

### Session list mirrors window grouping

- Sessions opened as tabs in the same window are pulled together in the list and rendered as one joined block, so the list reflects how terminals are docked.
- Docking or detaching a tab updates the list grouping accordingly.

### Fix: intermittent "claude · failed" on session start (Windows)

- A slow or failing `claude --version` check was treated as "not installed" and cached for 60 seconds, failing every session start during that window. The CLI is now confirmed via `where`/`which` before being reported missing.
