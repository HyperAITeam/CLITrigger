# v0.2.50 — VS Code-style dock guides for floating windows

Release date: 2026-08-24
Previous version: v0.2.49

## TL;DR

Dragging a floating session window (or tearing off a tab) now shows a VS Code-style dock guide in the center of the viewport. Drop on a side zone to dock the window to half of the content area — the app content reflows around it like a VS Code panel. Drop on the center to maximize into the content area, or on the pop-out icon to detach into a separate OS window.

## Highlights

### Viewport dock guides while dragging

- Dragging a floating window by its chrome, or tearing off a tab, displays a guide cluster at the center of the screen: left / right / top / bottom half-split zones, a center zone that maximizes the window into the content area (excluding the sidebar), and a separate icon above the cross for popping the window out into an external OS window.
- Existing behaviors are preserved: 8px edge snapping with quadrant resolution, drag-outside-60px pop-out, and stack dock guides. Priority order is dock > guide > edge snap > free.

### Content reflow around docked windows

- Dropping on a left/right/top/bottom guide zone docks the window to that half of the content area instead of overlay-snapping it, and the app content dynamically reflows to avoid the docked window — one docked window per edge, and docking a new one releases the previous.
- Resizing a docked window updates the reflow inset live; viewport and sidebar width changes recompute the dock geometry automatically.
- Dragging a docked window undocks it (Aero style), and maximizing undocks as well. Pop-out handoff and return clear the dock state.

### Fix: re-docking to the same edge

- Fixed a bug where dropping a window back onto the same guide zone it was already docked to left the window stranded at the drop position (docked size, potentially sticking out of the viewport). The dock geometry is now written directly to the DOM on drop, matching the maximize/snap paths.

```bash
npm i -g clitrigger@0.2.50
```

- **Windows (recommended)**: `CLITrigger-Setup-0.2.50.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.50.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
