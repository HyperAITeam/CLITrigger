# v0.2.43 — Password change from the login screen & forgot-password recovery

Release date: 2026-08-03
Previous version: v0.2.42

## TL;DR

You can now change your password directly from the login screen, and there is finally a recovery path if you forget it: run `clitrigger reset-password` on the server machine (or use Help → 비밀번호 초기화 in the desktop app) to clear the password and set a new one on the setup screen. Also fixes a desktop-app crash when opening the new terminal form.

## Highlights

### Change your password from the login screen

- A new "Change password" link on the login screen switches the form to current / new / confirm fields. On success you are signed in with the new password in one step — no need to log in first and dig into Settings → Account.
- Other sessions are signed out after the change, same as changing it from Settings.

### Forgot-password recovery

CLITrigger is self-hosted, so recovery requires access to the machine running the server:

- **CLI**: `clitrigger reset-password` clears the stored password hash and all active sessions. The next visit to the web UI shows the first-run setup screen where you set a new password.
- **Desktop app**: Help → 비밀번호 초기화 menu does the same and reloads the window into the setup screen.
- The login screen now has a "Forgot your password?" link explaining both options (English/Korean).
- Note: after a reset, anyone who can reach the server (including through an active tunnel) can claim the password until you set a new one — the CLI and the desktop dialog both warn about this.

### Desktop app: crash fix when opening the terminal form

- Fixed a main-process crash (`TypeError: sender.blurWebView is not a function`) triggered by the IME reset when entering the new terminal form. `blurWebView` is a `BrowserWindow` method and is now called on the window resolved via `BrowserWindow.fromWebContents(sender)`.

## Install / Update

```bash
npm i -g clitrigger@0.2.43
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.43.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.43.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
