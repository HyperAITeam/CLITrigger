# v0.2.54 — Web panel fills the tab and gets a fullscreen toggle

Release date: 2026-09-03
Previous version: v0.2.53

## TL;DR

A quick follow-up to the planner **Web panel** introduced in v0.2.53. The embedded page now fills the whole planner tab instead of stopping at 70% of the window height, so nothing is cut off when CLITrigger is maximized. A new **fullscreen** button in the panel toolbar expands the page over the entire app window and back without reloading it.

## Highlights

### Planner: Web panel height and fullscreen

- **Fills the tab**: the planner workspace only enforced a 70vh minimum height, and the embedded page has no height of its own, so on a large or maximized window the bottom 30% stayed empty and the page looked clipped. When the Web panel is selected, the workspace now takes the same fill-the-tab height as the Files tab. Page and list views are unchanged.
- **Fullscreen toggle**: a new button next to **Go** expands the panel over the whole app window. Click it again to return. The toggle only restyles the container, so the embedded page keeps its login, scroll position, and state instead of reloading.
