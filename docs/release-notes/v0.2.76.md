# v0.2.76 — Workspace attention badges, reliable SVN, and Documents replace the wiki

Release date: 2026-11-19
Previous version: v0.2.75

## Summary

The sidebar now shows a red count on each workspace when something there needs a look. SVN commands keep running when you switch tabs, and you can cancel an update. Several SVN file-name, commit, and diff bugs are fixed. The separate DB wiki is gone: project knowledge lives in plain Documents (Vault) files, and their tags drive AI context selection. Pop-out windows get maximize/restore buttons.

## Highlights

### "Needs attention" badges in the sidebar

- Each workspace in the sidebar (expanded list and collapsed rail) shows a red count of things to check.
- Sessions count when the agent starts waiting for input or finishes while you aren't looking at that pane. They clear once you look at the pane (pop-out windows included), the agent resumes, or the session is deleted.
- TODOs and discussions count when they complete or fail while you're in another workspace. They clear when you open that workspace.
- Counts are kept in memory, so a reload starts from zero.

### SVN: commands survive tab switches, plus bug and speed fixes

- Update, commit, revert, cleanup, and the other commands that change files now run on the server. Switch tabs or reload, and the panel picks up the running command's progress. If it finished while you were away, you see the result (conflicts or the new revision) once.
- Only one command runs per working copy at a time. Starting another one shows "another SVN command is still running" instead of failing on a working-copy lock.
- Updates have a **Cancel** button. Cancelling stops svn and runs cleanup, so the working copy stays unlocked.
- File names with `@` (e.g. `icon@2x.png`) now work for add, revert, commit, and delete.
- Names containing `&` or `'` display correctly and can be acted on.
- Selecting new or deleted files for a commit now adds or removes them first, as TortoiseSVN does.
- Clicking an unversioned file shows its full contents as an added-file diff.
- The update progress count no longer counts summary lines and includes replaced files. The new revision number is read correctly when svn prints localized messages.
- Results that arrive late no longer overwrite the newer status, log, or revision view.
- The file list no longer re-renders on every keystroke in the commit message or on every progress tick.
- "Load more" in the log fetches only the next page. Status runs its two svn queries in parallel.

### Documents (Vault) replace the DB wiki

- The wiki tab and its DB-only nodes are removed. Project knowledge is plain md/html/pdf files under the project.
- On first start, existing wiki nodes are written once to `.clitrigger/wiki/` as Markdown files with frontmatter tags. Existing files are never overwritten.
- Tags set in the app (stored in the DB) now feed automatic document selection for AI tasks, alongside frontmatter and `#tag` tags.
- Tags of files deleted outside the app are cleaned up.
- The MCP `remember` prompt now writes a Markdown document under `.clitrigger/wiki/` instead of creating a wiki node.

### Pop-out windows

- Maximize/restore button on frameless pop-out windows.
- Fixed a missing translation that showed a raw key in the pop-out top bar.

## ⚠️ Breaking Changes

- **MCP wiki tools removed**: `create_wiki_node`, `list_wiki_nodes`, `update_wiki_node`, and `delete_wiki_node` no longer exist. They are replaced by `list_vault_tags`, `set_vault_file_tags`, and `set_vault_tag_color`.
- **SVN HTTP API**: the endpoints that change files (`svn-update`, `svn-commit`, `svn-add`, `svn-revert`, `svn-delete`, `svn-resolve`, `svn-changelist`, `svn-cleanup`, `svn-propset`) now return `202 { jobId }` instead of the result, or `409` while another command runs. Read the outcome from `GET /api/projects/:id/svn-job`. Cancel with `POST /api/projects/:id/svn-job/cancel`. This matters only for custom scripts calling the API directly.

## Migration

- Nothing to do for the wiki. Old nodes are exported to `.clitrigger/wiki/` automatically on first start of this version. The old `memory_*` tables are kept but no longer read.
- If you have agents or scripts using the MCP wiki tools, switch them to writing Markdown files and to the `*_vault_*` tag tools.

- **Windows (portable)**: `CLITrigger-0.2.76.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
