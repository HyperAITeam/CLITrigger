# v0.2.75 — MCP sub-sessions, first-prompt delivery fix

Release date: 2026-11-19
Previous version: v0.2.74

## Summary

An agent running in a CLITrigger terminal can now open sub-sessions through MCP: separate terminal sessions that start right away and receive their prompt automatically. Sub-sessions appear under their parent in the terminal list. This release also fixes an auto-delivered first prompt that sometimes sat unsent in Claude's input box, and stops Codex from showing its update dialog when a terminal session starts.

## Highlights

### MCP sub-sessions (`spawn_session`)

- New MCP tool `spawn_session` creates a terminal session, starts it, and submits the given prompt as soon as the CLI is ready. No Send/Skip confirmation is needed.
- Each sub-session is its own CLITrigger terminal session with its own CLI process. You can open its window, watch it, type into it, stop it, or delete it like any other session.
- Pick the CLI per sub-session (`claude`, `codex`, or `antigravity`). The project default is used when none is given. The project's terminal sandbox setting still applies.
- Terminal sessions now get `CLITRIGGER_SESSION_ID` and `CLITRIGGER_PROJECT_ID` environment variables, so an agent inside one can name itself as the parent.
- In the terminal list, sub-sessions are indented under their parent with a ↳ marker. Sub-sessions whose parent was deleted show as top-level sessions.
- The lead agent collects results with the existing tools: `wait_session_state` (wait for `blocked`), then `read_session_output`, then `stop_session`.

### Fixes

- **First prompt left unsent** — when a prompt was typed into a CLI automatically right after startup, Claude Code could drop the Enter key, leaving the text in the input box. The text and the Enter key are now sent separately. This also affects automated tasks in interactive mode.
- **Codex update dialog** — interactive Codex sessions start with the update check turned off. Before, the Codex update dialog defaulted to "Update now", so an automatically sent Enter could start a global Codex update.


- **Windows (portable)**: `CLITrigger-0.2.75.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
