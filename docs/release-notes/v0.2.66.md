# v0.2.66 — Lighter memory and bundle footprint, clearer SVN sidebar actions

Release date: 2026-10-12
Previous version: v0.2.65

## Summary

This is a performance-focused patch release. Long-running tasks no longer make the task log view grow without bound, hidden terminal tabs release their GPU glyph cache, the server drops an unused per-session output buffer, and pop-out windows load a much smaller JavaScript bundle. The SVN sidebar now shows its commands as real buttons with a running indicator, and the large 50MB request body limit is now restricted to image upload routes.

## Highlights

### Performance

- **Task logs are capped.** Opening a task's logs now loads the most recent 2,000 lines, and live log streaming keeps the same window instead of growing forever. Very long tasks stay responsive.
- **Hidden terminal tabs use less memory.** Terminals in background tabs of a stacked window stay live (no output is lost), but their canvas renderer is only attached while the tab is visible.
- **Less server memory per session.** Each terminal session no longer keeps an unused 256KB output buffer; replay already comes from the database. A small per-task leak in token usage tracking was also fixed.
- **Smaller pop-out windows.** Main workspace pages are now split into separate chunks, so pop-out windows no longer parse them. The main bundle shrinks from about 1.67MB to 1.05MB.

### SVN sidebar: commands as buttons

- Views (local changes, log) remain navigation rows, while commands (Update, Update to revision, Cleanup, Properties) are now proper buttons with icons. Update is the primary action.
- A running command shows a spinner and an "in progress" label instead of just dimming.

### Request size limit

- The 50MB JSON body limit now applies only to the routes that accept base64 images. All other API routes use a 5MB limit.

```bash
npm i -g clitrigger@0.2.66
```

- **Windows (recommended)**: `CLITrigger-Setup-0.2.66.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.66.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
