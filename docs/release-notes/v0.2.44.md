# v0.2.44 — Git tab worktree support, live change detection, and window polish

Release date: 2026-08-05
Previous version: v0.2.43

## TL;DR

The Git tab now sees session worktrees: a new checkout selector lets you view, stage, commit, and discard changes made inside a session's isolated worktree, not just the main checkout. Git status and diffs also refresh automatically while a terminal session edits files — no more stale views or manual refresh clicks. Plus several desktop fixes: session diffs no longer miss early CLI edits, popout windows get a minimize button, terminal focus follows tab switches, and closed popout windows no longer leave orphaned dock chips.

## Highlights

### Git tab: work with session worktrees directly

- A new main/worktree selector at the top of the file status view lets you switch between the main checkout and any session's worktree.
- All git actions follow the selection: status, diff, stage, commit, discard, and conflict resolution now operate on the selected worktree. Previously, changes made by worktree sessions were invisible in the Git tab.
- The History view remains repository-wide (log/refs are shared), so it is unaffected by the selector.

### Live file change detection for Git views

- The Git tab and the session Diff panel now subscribe to a filesystem watcher while open. When a terminal session (or anything else) changes files, a `git:changed` push automatically re-fetches status and refs.
- Refreshes are coalesced (500ms) and scoped: the Git tab only re-fetches status and refs, so your commit graph selection is preserved.

### More reliable session diffs

- Fixed a race where the base-commit snapshot started after the CLI process spawned: early edits made by the CLI could get baked into the base and permanently disappear from the session diff.
- Opening the Diff panel before the snapshot finishes now waits for it instead of falling back to HEAD, so untracked new files show up correctly.

### Desktop window polish

- **Popout minimize**: frameless popout windows (Windows/macOS) now have a minimize button in the top bar. Restore via the existing dock chip.
- **Orphaned dock chips**: closing a popout window while a different project (or no project) was selected could leave its bottom dock chip behind, even across restarts. The dock tray now detects dead windows and reclaims their groups.
- **Terminal focus**: keyboard focus now follows when you click a tab title or create a new terminal with the + button — previously input silently went nowhere until you clicked inside the terminal.

## Install / Update

```bash
npm i -g clitrigger@0.2.44
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.44.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.44.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
