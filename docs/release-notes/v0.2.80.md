# v0.2.80 — Reliable image paste on desktop, plus a Claude · Codex usage widget

Release date: 2026-11-24
Previous version: v0.2.79

## Summary

Image paste in the desktop app could fail for minutes at a time with "powershell timed out after 10000ms". The desktop app now writes the image to the clipboard directly, with no helper process, so pastes go through in milliseconds. This release also adds a small widget to the Terminals tab that shows your Claude and Codex plan usage (5-hour and weekly limits). You can turn it off in Settings.

## Highlights

### Image paste no longer times out in the desktop app

- Image paste used to start a new PowerShell process for every paste to put the image on the clipboard. On some Windows machines, starting that process sometimes stalled for more than 10 seconds before PowerShell even started (for example, while security software was inspecting new processes), and every paste failed until the stall cleared.
- The desktop app now uses Electron's built-in clipboard instead. A clipboard write takes about 30 ms, and Claude Code reads the image the same way as before.
- The npm CLI (plain Node server) still uses the previous helper-process path.

### Claude · Codex usage widget

- A compact card at the bottom-right of the **Terminals** tab shows 5-hour and weekly usage for each CLI that has data. Bars turn amber at 80% and red at 95%.
- Hover a row to see when its data was read, or a bar to see when that window resets. A window whose reset time has already passed shows 0%.
- **Claude** usage comes from the same usage endpoint that Claude Code's `/usage` uses. **Codex** usage comes from the last rate-limit snapshot in Codex's session log, so it is only as recent as your last Codex run.
- It refreshes every 5 minutes, and right away when you open the Terminals tab, switch workspaces, or click the refresh button. The server caches results so that it does not hit Claude's rate-limited endpoint too often. If a Claude request is rate-limited, the widget keeps showing the last good reading.
- Not supported yet: Antigravity, and Claude on macOS (its credentials are stored in the Keychain).

### Turn the usage widget off

- **Settings → Terminal → Usage widget** (on by default). When it is off, the server stops reading usage entirely, and the widget disappears right away.

## Install / Update

```bash
npm i -g clitrigger@0.2.80
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.80.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.80.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
