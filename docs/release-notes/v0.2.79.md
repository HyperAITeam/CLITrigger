# v0.2.79 — Image paste no longer crashes the desktop app

Release date: 2026-11-24
Previous version: v0.2.78

## Summary

Pasting an image into a terminal could crash the desktop app with "A JavaScript error occurred in the main process — Error: write EOF". This release fixes the crash. A failed paste now just fails, and the app keeps running. It also adds an opt-in diagnostic log for image paste, so the cause of a failed paste can be tracked down.

## Highlights

### Image paste crash fixed

- Image paste puts the image on the OS clipboard through a helper process (PowerShell on Windows). If that helper exited before it had read the whole image, the desktop app crashed with an uncaught `write EOF` exception.
- That error is now handled. The paste request fails with the helper's exit code and error message, and the app stays up.

### Image paste diagnostic log

- **Settings → Terminal**: the "IME debug log" section is renamed **Diagnostic logs** and has a new **Image paste diagnostic log** checkbox.
- When it is on, each image paste writes one JSON line to `paste-debug.log`. The line records the session's status and process ID, the image format and size, how long the clipboard write took, whether the paste key (Alt+V) was sent to the CLI, and why the paste failed, if it did.
- The log lives next to the database: in the app data folder for the desktop app, and in `~/.clitrigger` for the npm CLI. It works for browser access as well as the desktop app.

### Readable clipboard errors on non-English Windows

- When the clipboard write failed, PowerShell's error message was garbled on Windows systems that use a non-UTF-8 code page (for example, Korean CP949). It is now emitted as UTF-8 and shows up readable in the log and in the API error.

## Install / Update

```bash
npm i -g clitrigger@0.2.79
```

Desktop app — pick the right asset:

- **Windows (recommended)**: `CLITrigger-Setup-0.2.79.exe` — installer with Start Menu shortcut, uninstaller, and auto-update.
- **Windows (portable)**: `CLITrigger-0.2.79.exe` — run directly, no install; no shortcuts and no auto-update (grab new versions manually).
- **macOS**: `.dmg` / **Linux**: `.AppImage`
